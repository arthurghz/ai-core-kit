## 3. Accessibility floor (WCAG 2.2 AA)

- Body text contrast ≥ 4.5:1; large text / UI objects ≥ 3:1.
- Visible `focus-visible` on every interactive element.
- Touch targets ≥ 44×44px.
- Honor `prefers-reduced-motion`; never signal by color alone.
